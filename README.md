## Sobre o Projeto

O site da Cor & Papel foi desenvolvido para apresentar os produtos da empresa de forma moderna, organizada e responsiva.

A primeira versão será um catálogo digital de etiquetas escolares personalizadas.

Todo o projeto foi planejado para crescer futuramente, permitindo a inclusão de novas páginas, painel administrativo, banco de dados e novas funcionalidades sem necessidade de reconstrução da arquitetura.

---

## Objetivos da Versão 1.0

- Catálogo de etiquetas escolares
- Navegação intuitiva
- Layout moderno
- Totalmente responsivo
- Integração com WhatsApp
- Hospedagem no GitHub Pages
